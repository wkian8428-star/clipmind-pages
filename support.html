🚀 快速入门

1
打开 ClipMind，完成首次引导设置
2
前往 系统设置 → 通用 → 键盘 → 键盘 → 添加新键盘，选择 ClipMind 并开启"允许完全访问"
3
在任意 App 中，长按地球图标切换到 ClipMind 键盘即可访问剪贴板历史

❓ 常见问题

为什么剪贴板内容没有自动保存？

iOS 系统限制，App 在后台无法自动读取剪贴板。请使用以下方式保存内容：

  • 打开 ClipMind 后内容会自动捕获
  • 使用分享扩展：在任意 App 中点击"分享"→ 选择 ClipMind
  • 使用 ClipMind 键盘扩展粘贴历史内容

如何启用 Face ID 保护？

前往 ClipMind → 设置 → 隐私与安全 → 开启 Face ID 保护。密码类型内容会自动加密。

iCloud 同步安全吗？

是的。iCloud 同步使用 Apple 的 CloudKit 加密传输，WingQing 无法访问您的数据。加密的敏感内容（如密码）不会参与同步。

如何删除所有数据？

ClipMind → 设置 → 数据管理 → 清空回收站。卸载 App 将删除所有本地数据。
